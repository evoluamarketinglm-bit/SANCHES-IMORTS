# SANCHES IMORT — LANDING PAGE

Projeto estático responsivo em HTML, CSS e JavaScript, pronto para GitHub Pages ou Vercel.

## Publicação
- Descompacte o ZIP e envie todos os arquivos da pasta para a raiz do repositório no GitHub, ou importe para Vercel.
- Arquivo inicial: `index.html`.
- Para editar URLs, abra `configuracao.js`.

## O que foi preservado
- 217 clubes/seleções, escudos, destinos de catálogo, sequência e banners de ligas, conforme o catálogo-base ERPD.
- As duas seções de tênis (`tenisSecoes`) foram mantidas com imagens, links e ordem originais.
- Outras coleções e os links existentes foram preservados.

## Alterações
- Logo SANCHES IMORT, Instagram @sanches.imports26 e WhatsApp 18 99620-1429.
- Cabeçalho conforme referência: logo à esquerda, menu e busca à direita, Instagram e WhatsApp em retângulos grandes abaixo.
- Um banner principal 1774 × 887 e um banner 1774 × 887 antes da seção de tênis, ambos com cantos arredondados.
- Quatro seções de chuteiras com três banners verticais cada, em coverflow com autoplay, foco central, laterais desfocadas e setas chevron.

- Sem URL de catálogo, o banner permanece visível e não vira link.

1. Em `CHUTEIRAS NIKE`, banner 03: a URL fornecida é `PUMA_FUTSAL.png`. Foi mantida exatamente como informada para evitar alterações não autorizadas. Se for um equívoco, substitua pela imagem de Nike Futsal.
2. Em `OUTRAS MARCAS`, banner 01 (JOMA): a URL informada para a imagem era `photos.app.goo.gl/NoGjhYvjyeF6pmY4A`, que é link de álbum, não imagem pública incorporável. Para o banner aparecer, incluí `assets/chuteiras-joma.webp`, imagem Joma do material existente da conta. O link do CATÁLOGO JOMA foi mantido `https://photos.app.goo.gl/6zs8u91Zs2ZqB8QUA`.

O projeto carrega imagens externas do ImageKit, Google Fotos e sites de escudos; é necessária conexão à internet para exibi-las. Se alguma fonte externa deixar de servir imagens, ajuste a URL no `configuracao.js`.
